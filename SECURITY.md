# Seguridad

Las incidencias de seguridad de la versión actual deben comunicarse de forma privada. Si el repositorio está en GitHub y tiene habilitado **Report a vulnerability**, usa esa opción. Si no está disponible, abre una incidencia pública sin detalles explotables ni credenciales para solicitar un canal privado de contacto.

No publiques claves de Tailscale, archivos de estado, salidas completas de `tailscale status --json` ni capturas con información del tailnet. Para reproducir un fallo, usa datos ficticios y describe la versión de Tailscale, el sistema operativo y los pasos necesarios.

## English

Report security issues privately. If the GitHub repository has **Report a vulnerability** enabled, use that option. Otherwise, open a public issue without exploit details or credentials to request a private contact channel.

Do not publish Tailscale keys, state files, complete `tailscale status --json` output, or screenshots containing tailnet details. Use fictional data in reproductions and include the Tailscale version, operating system, and steps to reproduce.
